## 独立検査の残り8件
- 普通のコードフェンス内に旧点検記録・新比較資料のマーカー風文字列があっても不活性。出力の元bytesと外側の正規候補Aを保持する。
- 旧点検記録と比較資料の境界が交差した場合、LF/CRLF/CRの3条件とも完全な比較候補へ格上げせず、内部挿入を拒否する。
- 未知version、余分な終端キー、別ID終端の3条件とも、後続のもっともらしい終端で修復せずEOFまで不完全領域として保護し、後続記録を候補へ漏らさない。
- 正常領域の厳密な直後への挿入を許し、選択中の既存文章・Unicode・旧点検記録を削除しない。

## 差分読解
