第一希望を採用する。既存 `FormulaReportAudit` のinventory/assessment/取得世代、`buildAuditMarkdown`、`parseMarkdownBlocks` の厳密領域判定、`insertDifferenceAtCursor` の位置保護、本文同一性による専用取消とPR87遅延caret取消を再利用する。固定記録を区別する最小v1開始/終了マーカーだけをMarkdown本文へ追加する。登録式/レポート/記録ID、生成日時、対象本文のUTF-8 SHA-256とUTF-16長を追跡情報とし、本文全文はプレビューで確認できるが固定記録に無条件複製しない。ハッシュは対象識別の手掛かりであって真正性や証明ではなく、出力だけから対象本文を復元できない。

固定領域内の引用/差分は外側の新出現として数えない。壊れた/将来/重複/入れ子/不完全なマーカーは不完全集計とし、後続終端から推測回復しない。正常な領域外の引用を除外しない。固定記録も挿入禁止領域として既存カーソル保護へ加える。

## 取得・編集・取消の境界
プレビューは同一renderの全件Markdownと本文を凍結し、SHA計算の非同期完了は同期epochで保護する。プレビュー/挿入は保存原本を暗黙再取得しない。既存明示照合のみを使用し、未照合/失効/保持本文一致未確認もそのまま固定する。親の本文/対象/関連付け/取得世代/位置変更とstorage通知を検知すると古いプレビューを拒否。保存通知だけで対象変更/削除とは断定しない。

挿入は未保存本文だけへ追加、選択文章は保持。保存/再計算/明示確認/履歴追加なし。取消は本文完全一致と対象・編集世代が保たれる直後のみ、安全でなければ理由を示して保持する。任意外部writerとの原子的排他、保存原本の常時最新性、数学的証明、真正性は保証しない。過去記録は自動更新しない。
