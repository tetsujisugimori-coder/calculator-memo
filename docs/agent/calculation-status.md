# 変更状態とエラー詳細診断

2026-10-20 (JST)。基点 main `ebb0bef872f7ef033d3529047aa94366ab2b34a0`（PR #39 merge）。数値評価・保存形式・一括確定は変更しない。

## 現状と今回の範囲

従来は編集/失敗時に全計算のevaluationStateをstaleにし、全体確定停止を各カードへ表示していた。PR #38の前後依存グラフ、PR #39の試行診断はあったが、変更元/影響/無関係の表示、i詳細、Mermaid文字列のUIはなかった。

今回 `buildCalculationStatus` は既存の解析・変更影響を利用する純粋な表示モデル。数値評価を追加せず、元オブジェクト・未知フィールド・保存データを変更しない。式の文字列検索による新依存解析や新しい計算規則はない。

## 変更と全体確定は別

編集画面開始時のsnapshotを比較元とし、手動再計算成功時に新しい比較元へ更新する。前後両グラフから直接変更・削除・参照先変更・旧変数束縛変化とその下流候補を求める。IDのみの表示移動や未知metadata変更は個別影響を生まない。旧変数の影響は静的候補なので未確定と明記する。

手動モードの既存stale/attemptErrorと原子的一括確定はそのまま。無関係なブロックには変更/影響/自身の失敗ラベルを付けない。ただし値は全体確定の観点では保持中結果であり、メモ上部の全体停止と結果captionは残す。個別の「通常」はそのブロックの変更/問題が確認されていないという意味で、全メモの確定成功を意味しない。詳細にも全体未確定を表示する。

成功時に比較元と診断を更新して変更/影響を解除。失敗時は旧値・旧error・全体staleを保ち、今回の原因/下流診断を非保存の派生情報として保持する。再編集で前回試行を無効化。試行snapshot一致も検査する。

旧変数のみの既存自動逐次計算は互換性のため維持し、そこで更新したsnapshotを比較元とする。新しい自動再計算経路は追加しない。

## 再読込時の制約

比較元はエディタのメモリだけに置く。現行JSONには過去の完全な変更前データや今回の詳細試行記録がない。staleの保存を開き直した場合は、以前の直接変更元・影響範囲を復元できないため「再計算状態不明」と説明する。開いた後の新しい変更は区別するが、以前の不明部分を正常と断定しない。保存signatureを推測で完全snapshotへ復元しない。currentの保存は従来signature検証で確認する。

## 診断の証拠段階

- 構造確認: 既存parser/参照/SCCの解析結果。数式解析失敗、参照切れ、不正参照、自己、循環と下流、旧変数の先行定義欠如を区別。数値実行済みとは称さない。
- 今回試行: PR #39の実診断だけ。旧フェーズで確認した複数失敗は保持。IDフェーズは最初の失敗で停止するため未試行の数値エラーは不明と明記する。原因収集目的の追加評価はしない。
- 保存済み: 旧errorは現在の式の失敗証明ではない。失敗時の式/影響範囲は記録から確定できないと表示し、修正後の式を過去原因に結びつけない。旧自動計算の確定errorは「保存済みエラー」であり未実行と誤表示しない。

下流失敗は確定ID辺だけから導く。旧変数の不確定候補は確定原因伝播に使わず、失敗再代入後に以前の値で成功する消費側を誤って失敗にしない。複数の循環/失敗原因が同じ下流へ届く場合は、到達する既知原因を列挙する。表示可能な原因だけを示し、停止後の隠れた数値原因を一件へ集約しない。

i詳細は説明、対象式（証拠がある段階のみ）、原因/影響、修正の手掛かり、試行範囲を示す。表示番号・式・内部IDを併記し、存在する対象カードへスクロール/focusできる。全体変更一覧は個別原因一覧と混同しないよう「メモ全体」と明示する。

## MermaidとUI

従来 `toMermaid(graph)` の出力は不変。任意 `nodeStates` 指定時のみ、証拠に沿った変更/影響/原因/下流/不明ラベルとclassを上書きする。安定ID、出力順、重複辺除去、数値entity escapingを維持。ID辺と不確定変数辺は既存graphそのもの。全体staleを全ノードの個別変更警告にしない。

折り畳み欄にreadonly Mermaid文字列とcopy操作を置く。コピー失敗時は手動選択案内。Memo Nexusへ送信せず、数値再計算も行わない。既存通常図との互換性を保つため新しいclass定義はnodeStates指定時だけ追加する。

iボタンはaria-expanded/controls、短いラベルは色に依存しない。両テーマ・狭幅・文字拡大を検証する。画面切替は現行modal unmountでstate破棄。将来同一mountで外部データ差替えを導入する場合は比較元の世代管理を追加検討する。

## 検証・制約

単体で直接/多段/無関係、編集復元・削除・前後辺・並べ替え、旧候補/スコープ、数値未実行、実失敗/複数原因、rollback、成功解除、JSON再読込不明、未知metadata/非破壊性、通常Mermaid互換と実parserを検証する。独立レビューの保存旧error誤帰属・旧自動errorの未実行誤表示・循環と参照切れの合流で既知原因が欠ける問題は再現後に修正し回帰を残す。

既存計算/保存/安全上限/精度/非破壊読込テストは期待値を変えず維持。GUI既存の各カード全体停止assertは上部集約へ変更するが、元の数値/rollback期待値は変えない。最終件数/CIはLOGおよびPR本文に記録する。

対象外: エンジン全面改修、自動/部分再計算、部分確定、永続詳細診断履歴、Mermaid図の本格GUI、Memo Nexus直接送信。実iPhone Safari、ソフトキーボード、VoiceOver、長期保存・全幅は別途未検証。
