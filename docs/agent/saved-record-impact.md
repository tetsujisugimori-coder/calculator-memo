# 保存済み計算記録の変更影響分析

## 調査と設計判断（2026-10-22 JST、Issue #55）

PR #54 のマージ済み main e9601e43e68f32328b4a42296e868cd84c7071c0 を調査した。既存の比較は式・モード・実使用元・使用値・結果・順序の独立差分と取得時点固定、全文確認/コピー/downloadを実装済み。今回はこれらを再利用し、過去の実使用依存経路と独立分類を加える。

現在メモの analyzeMemoDependencies / analyzeDependencyImpact は構文と旧変数候補・現在の鮮度を扱い、前後の辺を合成する処理もある。そのまま過去記録へ適用すると、未使用候補や存在しない混合経路を当時の根拠にしてしまう。第一希望の既存処理再利用は、比較モデル、数値表現、validator、DependencyGraph/Edge 型・辺キー、Markdown補助、UI保存取得境界に限定する。実使用 inputs を読む小さなアダプタを新設し、式の正規表現解析・再評価・新しい描画エンジンは追加しない。

## 独立する判定

- 直接変更（観測差分）: 式、モード、実使用参照元、実使用内部値、保存された参照枠設定、記録間の追加/削除。値の差は利用者の直接編集や最初の原因を証明しない。未使用参照枠の設定差は観測項目として明示するが実使用辺にしない。
- 波及変更候補: 上記の起点から、その側の実使用辺で到達できる後続。直接差と波及候補を同時表示でき、結果不変でも候補を消さない。
- 結果差分: 表示/内部結果を独立比較。結果だけの差は直接変更の起点にしない。
- 順序差分: 本文位置・実行順。これだけでは式/値の変更や波及起点としない。旧変数の意味が変われば実使用元/使用値差として別途現れる。
- 判定不能: 未対応/不正形式、観測可能な記録内不整合、分析上限など。既知の差を失わず、未知を変更なしに置換しない。未知付随フィールドは従来の全体警告として別掲し、ブロック別の不整合/上限の判定不能件数には加算しない。

v1確定記録は全ブロック成功・先行実行元への参照だけを受け入れる。循環・欠損元・重複ID・エラー/結果なし・未対応versionは既存validatorと読込保護で拒否される。これらを正常に記録された失敗履歴として捏造しない。形が有効でも、使用内部値と元ブロック結果、入力kindとモード、ID入力名/参照枠/参照元の不整合は再計算せず検出できる。その辺と不整合上流を経由する伝播を根拠として認定せず、理由を表示する。構文・数値再現性・真正性までは確認しない。

## 経路と容量

前後のグラフを別々に保持。辺は元ID、利用側ID、種類、実使用入力名で識別する。参照先変更は削除辺/追加辺と対応する参照元差として表示し、使用値だけの変更を辺の追加削除にしない。旧変数は保存済みの実使用元IDだけを使い、再代入候補を追加しない。

各起点から幅優先に代表経路を求める。全経路列挙ではなく、複数起点を独立表示する。各側の探索100,000ステップ、出力する経路ノード計10,000の上限を設け、超過したら不完全・判定不能を明示する。取得済みの既知差分と経路は保持するが、列挙されなかった経路を影響なしとは扱わない。保存履歴100件/500,000 UTF-8 JSON bytesの上限は変えない。

## 表示・出力・非破壊性

既存比較画面に展開式の分析一覧を追加。色だけに頼らず分類名を表示し、選択ブロックの前後詳細と経路・辺の根拠を読める。長いID/式は既存折返しと縦並びを利用し、一覧は開いた部分だけ詳細描画する。新Mermaid描画は必須でないため導入せず、一覧経路を基本とする。

比較Markdownに同じ分析モデルを追記する。既存の全文確認・コピー・安全なファイル名/.md・動的フェンス・HTMLエスケープ・400万文字の出力上限を維持。超過時は部分レポートを返さない。Memo Nexus等へは手動受渡しのみ。表示上のメモ名は取得時点の識別情報であり当時のタイトルではない。

画面を開いたときの保存原本と同じ取得世代で、前後比較・分析・出力を行う。外部更新は既存の明示再取得に従う。draft・試算・現在値補完、再計算、再現検証の自動実行、保存・日時更新・記録追加はない。計算エンジン/保存形式/rollback/保存競合対策に変更しない。

## 保証しないこととロールバック

依存経路は数値変化の原因、数学的証明、真正性を保証しない。複数起点のうち唯一の原因を決定しない。JSONにない説明/原因/履歴を生成しない。実iPhone Safari・VoiceOverは未実施なら別途未検証と報告する。

本PRをrevertすると分析表示とMarkdown追記のみを取り除ける。保存移行/履歴削除は不要。検証実測はLOGと最終HEADのPRを参照する。
