# 依存関係の変更比較と試算連携

## 範囲と基点
PR #43 merge後の main `8923e0c85f685a8631f5967e25e40894f0d043ba` からの表示統合。計算エンジン、JSON、保存操作、旧変数の意味論、試算の作成/反映/失効処理は変更しない。

## 表示の意味
- 既存の「現在の依存関係」を既定とし、通常Mermaid出力を維持。「変更前後・試算」で比較図を選ぶ。
- 変更前とは編集画面を開いた時点、または最後の全体再計算/一括反映時点の既存baseline。永続保存済み原本と同義ではない。読込前の変更履歴は再構築しない。
- 安定したblock IDでbefore/afterノードを結合。現行式を表示し、削除ノードだけ変更前の式を残す。ID参照の並べ替えだけでは別ノード/辺としない。
- 辺の同一性はsource/target/kind/certainty/variable。追加は「＋追加」（確定辺は太線、不確定候補は点線を維持）、削除は「−削除」点線。参照先変更は削除と追加で表し、根拠のない一対一対応を推定しない。同一ノード間でも旧変数候補とID参照、確定/不確定は区別する。
- 解析失敗で辺を取得できなかった場合は「変更不明」として過去の辺を残す。削除と断定しない。全体解析制限でgraph.nodesが空でも実ブロックの状態キーで存在を確認し、残した過去の式を「変更前の式・現在は解析不能」と明記する。
- 影響は既存analyzeDependencyImpactのbefore/after両グラフ上の到達範囲。直接変更・変更の影響対象・依存関係上の影響なし・影響範囲不明を分ける。再代入の候補や解析不足を確定依存と扱わない。

## 試算との境界
useCalculationTrialのvalidTrialが真のときだけ既存trialを渡す。memoKey/sourceRevision/入力同一性/編集世代など既存安全策を置換しない。比較モデルは数式評価を呼ばず、rowsのdifferenceState/resultText/differenceとreport診断を使う。

構造上の影響と数値比較は直交する。A=100→200、B=A+50、C=B*2、D=80、E=A*0ならA変更元、B/C/E影響対象、D影響なし。試算後B150→250/C300→500は数値変化あり、E0→0は影響対象だが数値変化なし。エラー/未試行/有効な旧値なしは数値比較不可。試算前・失効後に数値変化を確定表示しない。比較相手は保持中の旧結果でありbaseline式の再評価値ではない。

図に状態ラベル、比較一覧に旧結果→試算と内部差分を表示する。選択時のi詳細は有効試算の既存診断を利用し、複数原因を保持。試算結果は未反映で、計算確定/永続保存の意味を持たない。

## 操作・安全・制約
既存ノード移動/強調/明示編集、診断、通常コピーを維持。比較コピーは比較図の同一Mermaid源から生成する。削除ノードは記録表示のみで移動/編集しない。表示失敗は一覧/コピーへfallbackし、計算データを変更しない。

Mermaidは既存strict設定とSVG再構築sanitizerを継続。ユーザー式はdecimal entity化、描画時は固定ラベルでlayoutしてtextContentで戻す。辺の追加/削除/変更不明ラベルも固定語のみ。最大128ノード/256辺の既存描画上限はunionにも適用し、前後それぞれ上限内でもunionが上限超過する場合は一覧/コピーへ切り替える。

独立レビューで全体解析制限時の削除誤判定と追加太線のCSS上書きを修正。UIは折り返し対応。実iPhone Safari/VoiceOver/実OSクリップボードは自動WebKit検証とは区別する。

## 検証とCI影響
既存658単体を維持し、比較モデル・Mermaid文法/安全投影・失効/削除ノードのcomponent回帰を追加。GUIは既存6条件/既存検査を維持し既存stageに比較を統合。PR #43の2worker、SHA照合、7日保持、30分timeout、成功代表PNG/失敗前からのtrace、全geometry検査は変更しない。実測結果はLOGとPRに記録する。自動再試行、期待値緩和、CIの再最適化は行わない。

### 複合状態のMermaidクラス
Mermaid 11.12.2の実パーサーでは `class A changed,error;` が2状態ではなく単一クラス名になるため、状態ごとに独立したclass文を生成する。通常図も比較図も同じ生成処理を使い、ノードID・依存辺・ラベルは変えない。SVG側の許可属性は拡張せず、複合状態の色・線・操作対象クラスを失わないことをパーサーDBとGUIで検証する。

### タッチ操作中の位置安定
試算の行が図の上に増減した状態で、Chromium mobileはsummaryへのfocus時にscroll anchoringを行い、touchstart後とclick前で対象が移動することがあった。実イベント記録で再現し、計算メモ編集部だけをアンカー候補から除外する。図のパン・拡大や明示的なブロック移動は維持し、modal全般や他画面には設定を広げない。固定待機、強制クリック、自動リトライで隠さず、既存6条件の実操作で再検証する。
