# 計算根拠の固定引用

## 第一希望と既存契約

登録式のレポート編集から「計算根拠を引用」を開く。候補は同じ登録式のレポートへ**保存済み**の根拠リンクの記録だけ。計算記録自体には formulaId がないので、名前や式の一致を使って関連を推測しない。未保存の関連付けは通常保存してから使う。選択ブロックの式、当時の実使用元IDと内部値、表示結果と内部結果、記録ID・日時を既存の表示部品で確認し、挿入前プレビューから追加する。

既存 EvidenceRecord は全計算成功後、保存が成功した確定記録だけを表す。未確認・エラー・結果なし・状態不明を成功記録へ変換して候補にしない。不正な記録は取得・照合不能。保存済みの現在メモや未保存draft、未確定試算から、過去の実使用値を補わない。

## 保存方式の比較

- 採用: 通常Markdown本文に可読textフェンスとversion付き追跡JSONフェンスを対として挿入する。引用ID、登録式ID、メモID、ブロックID、引用日時、保存記録全体を固定する。レポートの既存body保存・コピー・Markdown出力に同じ内容が残る。
- 別metadataや既存linkの拡張: 閲覧用JSONを隠せるが、新フィールド、旧版の未知形式停止、移行・ロールバック設計が必要になる。今回の小規模統合では採用しない。
- 識別子だけの埋込み: 元記録欠落時に当時の値を復元できないので不採用。

保存JSONのversion・フィールド・validatorは変更しない。既存本文100,000文字、全レポートUTF-8 JSON 1,000,000バイト、確認履歴20件は維持。記録全体を含むため引用が大きくなる。上限では切り捨て・履歴削除・自動縮約をせず挿入または保存を停止する。旧版は通常のMarkdownとして保持できるが、引用の追跡状態を表示できない。ロールバック前の原本JSON退避を推奨する。既存レポートを自動移行しない。

## 挿入・取り消し

編集欄のカーソル位置へ追加する。範囲選択なら先頭へ挿入し、選択した本文も保持する。安全な改行を添えるが既存の文字列は削除しない。直後は「直前の引用を取り消す」で挿入前の本文へ戻せる。後続本文編集、テンプレート挿入、保存成功では取消を失効させ、後続内容を消さない。ネイティブブラウザUndoの互換性は保証しない。コード・数式ブロック内への挿入は、引用の追跡フェンスが本文として認識されなくなるため停止し、ブロック外へカーソルを移すよう案内する。引用操作・閲覧・原本再取得だけでは保存も確認履歴追加も再計算もしない。

挿入直前には保存原本を再読して取得時rawと照合し、同一タブ更新や取得失敗を検知した場合も本文を変更しない。他タブのstorage通知後は未照合にし、明示再取得を要求する。保存は既存ロック・競合・読戻し経路のままである。任意の外部writerとの完全な原子的排他は保証しない。

## 状態と比較範囲

引用の照合状態はレポート利用者の明示確認状態と別に表示する。数値の数学的正しさ・証明・JSON真正性の保証ではない。既存 formulaReportAssessment 条件は変更しない。

- 一致: 取得した保存記録全体と引用時snapshotが一致し、可読引用本文もmetadataから再構築した本文に一致する。
- 元記録の変更: 同じIDの記録が異なる。選択ブロック以外の記録内変更も対象。勝手に引用を更新しない。
- 欠落: メモ・記録・選択ブロックが見つからない。引用本文は残す。
- 照合不能/根拠未照合: 未取得、読込失敗、更新通知後、未知/不正形式など。欠落とは区別する。
- 引用本文の編集: 可読本文と追跡payloadの対応が崩れた。整合扱いにしない。
- 現在の保存済み根拠リンクから外れた: 元記録の有無とは別に示す。引用内容を削除しない。

比較はそのIDの保存記録に限定する。現在のメモ本文、新しく追加された別記録、外部文献は自動比較しない。任意編集可能なMarkdownは署名ではない。可読本文とpayload両方を整合して書換えた場合の真正性は判別できない。追跡フェンスを丸ごと削除した普通の文章は自動認識できない。未知形式・壊れた引用情報は本文のまま保持し、照合不能を表示する。

## 操作・表示・検証

引用元ボタンは既存RecordInfo/BlockInfoを用いる読み取り専用モーダルで、該当する記録とブロックへ直接移動する。編集中本文を閉じたり破棄したりしない。選択欄は番号と短いIDで表示し、選択後の詳細には完全なメモ名・ID・式・値を示す。WebKitのネイティブ選択肢による横幅膨張を避け、既存のnative select描画方式を再利用する。長いID・数値・コードは折返し、色だけに頼らず状態文章を表示する。章一覧/Markdownプレビューは既存parserを使い、引用内の見出し風文字列を章に数えない。

単体と既存Chromium/WebKit6条件で確認する。実施結果はLOGとPRの最終HEAD実CI参照。WebKitモバイル自動試験は実機iPhone Safari・VoiceOver・OSクリップボードの保証ではない。
