既存の保存済み取得スナップショット、比較詳細、`evidence-impact.ts` の前後別 graph/edges、独立した分類、起点別代表経路を再利用する。分類・経路探索・計算・保存は増設しない。`dependency-mermaid.ts` のID符号化と安全な文字列、SVGの再構築/ラベル復元、Mermaid直列描画だけを共有する。現在メモへ移動する `DependencyGraph` UI は分離し、過去図から現在編集へ誘導しない。

## 操作

保存済み計算記録で2記録を選び、「変更影響分析」→「変更影響を図でたどる」を開く。「変更前の図」「変更後の図」で各記録だけを見る。矢印は実使用元から利用側へ向かう。旧変数も候補ではなく記録された実使用元である。

図のブロックをクリック・タップ・Enter/Space、または番号の選択肢/ID一覧で選ぶ。「代表経路の起点」を選ぶと既存分析の経路が太線になる。「選択経路だけ表示」はそのブロック列の連続する辺だけに絞る。途中ノード間の別の辺を勝手に代表経路へ追加しない。前後詳細は同じ保存取得時点の式・モード・本文/実行順・参照名・使用値・表示/内部結果を使う。

番号は比較一覧の順であり、IDの代わりではない。長いIDでnative selectが小画面を押し広げないよう、選択肢は短い番号にし、完全IDは折返す本文と一覧に表示する。デスクトップは図/詳細を並べ、狭幅では縦並び。図内スクロール・50〜200%拡大縮小、文字ラベル・フォーカス・選択状態を備える。色だけで分類しない。

## 選択と取得世代

側切替ではブロックIDと起点IDを維持する。片側にないブロック/起点の経路は明記し、代替選択しない。比較ペア変更・前後入替・明示再取得では図を閉じて選択/経路をリセットする。再取得カウンタを使い、同じ時刻・同じ記録IDの取得でも別世代として扱う。外部保存を検知しただけでは表示内容を混ぜない。

非同期描画は取消フラグを持ち、古い側・閉じた図・古い取得世代の完了を破棄する。図を選択しただけで再計算・再現検証・保存・日時更新をしない。Markdownは表示用フィルタを通さず、従来の分析全体から生成する。

## 分類・経路の保証

直接変更、波及変更候補、結果差分、順序差分、判定不能は同時成立する独立ラベル。結果のみの変更や順序差だけを起点にしない。第一原因、単一原因、数学的証明、真正性は保証しない。

代表経路は各起点/対象/側ごとに既存分析が返した1本であり、全経路ではない。同じ2ブロック間の複数入力は図で1本になる場合があるが、詳細は名前と内部使用値をすべて表示する。特定入力だけの原因とは推定しない。不整合として除外された辺や下流は正常な経路として強調しない。

経路がない場合、完全な分析で到達関係が確認されない場合と、不整合/上限のため判定不能な場合を区別する。現在メモ、draft、試算、未使用参照候補で穴を埋めない。

## 分析上限と描画上限

既存分析上限は各側100,000探索ステップ/10,000経路ノード。達した場合も既知経路を残し、不完全を明記する。描画は別に128ブロック/256入力辺/250,000文字、SVG4MB/寸法50,000を継続使用する。描画だけの超過は有効な保存記録を不正扱いしない。表示件数を0とし理由を示し、条件内の選択経路表示・既存一覧・詳細・絞り込み前のMarkdownへ退避する。黙った切捨てや「参照なし」への置換はしない。

図の準備/描画失敗は分析失敗と区別し、既存比較と生成できたMarkdownを保持する。保存100記録/500,000 UTF-8 JSON bytes、schema、engine、精度/-0、試算/rollback、保護/競合対策は変更しない。

実行用fixtureは `tests/evidence-impact-graph.test.ts`、`tests/saved-evidence-ui.test.ts`、`e2e/scenario.mjs` の saved-record-comparison に置く。これは人工の保存記録で、ユーザーの実データではない。

| データ/操作 | 期待値 |

| A100→120、B=A+50、C=B×2 | C選択のA起点 A→B→C、B起点 B→C。Cの使用値150→170、結果300→340 |
