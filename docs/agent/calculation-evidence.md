# 計算確定時の根拠スナップショット

2026-10-22 JST。調査基点: main bf09f8d（PR #50 merge）。

## 実装前調査と設計判断

既存 execution-plan は旧変数を本文順で全て評価した後、ID参照を依存順に評価する。旧変数の再代入失敗は直前の成功値を維持し、手動メモは一件でも失敗すると全体の結果を rollback する。試算は同じ純評価器を呼ぶが永続保存しない。鮮度 signature は構造の比較情報であり、過去に実使用した値の履歴ではない。PR #50 の Markdown は現在の保存値と使用値確認不能を既に区別する。これらを再実装せず拡張する。

「根拠記録の確定」は全件の計算成功に加えて明示的な「保存する」の書込み・読戻しが成功した境界とする。再計算／試算反映の直後は未保存候補である。プレビュー、通常編集、失敗、取消では確定記録を作らない。同じ内容を繰り返し再計算した候補は別々に記録する。後続の編集・失敗で失効した未保存候補は保存対象にせず、保存済み履歴は変えない。旧自動モードは既存の保存時評価と同一パスで取得し、部分成功の保存挙動は維持するが根拠は全成功時だけ記録する。

note 単位の任意 calculationEvidence.version=1 に一括記録を追記する。計算日時、保存要求時刻、一意 ID、評価器方式 calculator-memo-v1、各ブロックの本文位置・実行順・入力式・モード・参照枠・実使用入力・結果を保持する。評価器の scope.get を観測し、has による構文確認や依存候補は使用とみなさない。旧変数の出典は成功した代入の後だけ更新する。数値は IEEE-754 round-trip 文字列とし -0 を保持、表示丸め文字列とは分ける。

履歴は最大100回、UTF-8 JSON 500,000バイト。新規追加で超える場合は書込み前に停止し、旧履歴・保存原本・編集内容を維持する。黙った古い履歴の削除は行わない。手動モードで記録候補を作らない通常編集保存と既存履歴の閲覧は可能。旧自動モードでは保存時に計算するため、上限到達後の成功計算の追加保存は拒否する。原本JSON退避後、新しいメモで計算を継続できる。履歴だけの削除UI・自動圧縮は今回対象外。

保存形式のトップレベルversion=1は変更しない。履歴がない旧データはそのまま読み込め、過去使用値は確認不能。未知fieldは既存の保持規則を継続し、履歴の未対応versionや不正構造は非破壊保護対象。保存済み履歴をdraftから置換せず、元noteの履歴へ追記する。

保存は原本の文字列一致を検査し、書込み後に読戻す。対応環境では同一Web Lockを使うアプリ内writerを直列化し、他タブ変更は競合として停止する。localStorageには原子的CASがなく、古いアプリや外部の非協調writerとの完全排他・永続媒体への物理flushは保証しない。保存成功と数値計算成功を混同しない。書込み後の読戻し例外は「保存された可能性がある」不確定結果として扱い、盲目的に再送せず、書込みを停止して再読込確認を促す。保存待ち中は編集/取消/Escapeを停止し、候補は原本世代に結び付ける。未保存候補も100件/500,000バイトで反映を拒否し、以前の候補とdraftを維持する。

Markdown生成は再評価しない。保存記録を現在の保存結果・現在の依存図とは別項として表示する。記録からの明示的な再現検証は既存評価器で数値・実使用元・順序の整合を確認するが、利用者が変更可能なJSONの真正性や数学的証明は保証しない。将来の評価器変更は新方式識別を要し、旧記録との差を改ざんと断定しない。

## 非同期保存中の離脱境界

共有ロックによって既存の自動保存にも待機時間が加わる。DOM入力完了、計算成功、履歴への追加は保存完了と同義ではない。アプリの現在データと最後に書込み・読戻しが成功したデータの差を未保存として表示し、差が残る間はbeforeunloadで離脱警告を要求する。古い保存処理が終わっても新しい入力の未保存状態を解除しない。失敗時も未保存を維持し、ロックを迂回する終了時書込みは行わない。

ブラウザが警告を表示するかは環境・操作履歴に依存する。モバイルのアプリ強制終了、OS停止、利用者が警告を無視した離脱で未保存変更を保持できるとは保証しない。保存中の表示が消えてから再読込する。GUIは遅延ロック下で未保存状態・離脱ガード・旧原本不変を確認し、ロック解放後の正確な最新入力の保存を確認してからreloadする。

## 保存済み記録の一覧・比較（Issue #53）

調査基点: PR #52 merge後のmain `939828ca6673530d4b855b51479ed7e7a403996d`。既存の履歴validator・記録型・canonical数値・保存済み原本loadData・Modal・Markdownのescape/fence/filename/容量制限を再利用する。PR #49/#50の「現在参照元のレポート」、#51/#52の「確定時の実使用履歴」に対し、今回は保存済み過去同士の閲覧・比較だけを追加する。評価器・保存writer・記録確定境界・保存形式は変更しない。

保存済みメモ詳細の「計算記録を開く」から、日時・保存要求時刻・ID・計算ブロック数を一覧表示する。保存要求時刻は保存完了時刻ではない。詳細はその記録内の式、本文順、実行順、実使用元ID・値、表示結果・内部結果を示す。現在のブロックは参照しない。メモ名は取得時点の識別用metadataで、過去のタイトルを保証しない。記録0件は履歴なし・過去値確認不能、1件は詳細のみ。

初期の前後は配列の追記順で最後の2件を選ぶ。端末時計の一致や逆転で並べ替えない。前後入替は比較方向だけを変える。Stable block IDだけで対応付け、式・計算モード・実使用参照元・実使用内部値・表示結果・内部結果・本文順・実行順の8項目を独立に判定し、同時に示す。片側のみのブロックは「比較対象の記録間で追加／削除」であり、本文全体の編集履歴ではない。

実使用入力は(kind,name)の対応で比較し、読み取り配列の順番や未使用の参照候補だけの変化は使用元変更としない。参照元が違い値が同じ場合は参照元だけ、表示が同じでも内部文字列が異なる場合は内部値だけの差を保持する。数値を再丸めせずcanonical round-trip文字列を使い、-0と0も区別。未知の付随fieldは変更せず「未解釈・未比較」を明示する。「変更なし」は比較対象の既知項目の範囲である。不正・未対応version・欠けた必須項目は既存の非破壊読込保護で比較不可とし、現在メモから推測補完しない。

開く操作でloadDataが読んだ1世代をローカルsnapshotへ複製し、選択・詳細・比較・出力は同じ取得世代だけを使う。storage通知は外部変更のお知らせだけで自動差替えしない。「最新の保存内容を再取得」で明示的に世代を切り替え、同じIDがあれば選択を維持、消えたIDは選択解除して警告する。別の最新記録へ黙って置き換えない。再取得失敗時は古い比較と新しい保護状態を混在させず、比較と出力を停止する。閲覧機能自身は再計算・検証・保存・日時変更・記録追記を一切しない。

大量の記録でも閉じた詳細本文は展開までmountせず、概要と全文Markdownを維持する。純粋な比較モデルは複製・凍結する。同じモデルからMarkdownを生成し、全文確認・コピー・.mdダウンロードを提供する。Reactのtext表示と既存のMarkdown literal/dynamic code fenceを使い、HTMLを描画しない。既存の4,000,000文字出力上限を超えたら黙って切らず生成を停止し、可能なら画面比較は残す。コピー拒否・download開始失敗を示し、ブラウザへのdownload要求をOS保存完了とは言わない。実生成例は[evidence-comparison-example.md](evidence-comparison-example.md)。Memo NexusはMarkdown手動受渡しのみで、直接通信や表示互換を保証しない。

保証は保存された記録の既知項目同士の差まで。記録にない原因・解説・過去本文は確認不能。因果関係・暗号学的真正性・数学的証明は保証しない。現在の試算比較は未来の反映候補、今回は保存された過去の比較であり、別画面・説明で区別する。新しい依存図や現在図の流用、記録削除・復元・圧縮はなし。既存100記録／500,000 UTF-8 JSON bytes上限はそのまま。

### 設計上の選択と残る課題

第一希望は既存の保存済み原本と純粋モデルを使い、評価器やwriterを変更せず境界を保つ方式。採用した。次善策の編集画面データ・現在の依存図の流用は未保存混入や当時情報の推定につながるため採用しない。履歴の容量整理は今回対象外であり、上限到達時は既存案内を維持する。実iPhone Safari/VoiceOver、OS物理保存、Memo Nexus実画面は実施しなければ未検証。ロールバックは本PRの閲覧UI/純比較/文書追加をrevertするだけで、保存データ移行や履歴削除は不要。
