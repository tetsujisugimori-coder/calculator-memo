# 計算ノートの変数（2026-10-19）

## 範囲と評価

文章・数式・計算ブロックを持つメモ（plain-calculation）の計算ブロックだけで使用する。通常電卓、履歴、単独計算メモ、URL式、Memo-Nexus側は従来仕様のまま。本文・KaTeXは実行しない。

新規計算ブロックは `evaluationMode: "note-variables"` を持つ。ノート全体を上から走査し、その都度空のMapを作る。先行する成功した定義だけを参照し、結果は数値として保持する。各式は検証済みASTを一度だけ評価し、表示丸めされた文字列を変数値に使わない。

- `price = 1200`, `quantity = 5`, `subtotal = price * quantity`, `tax = 0.10`, `total = subtotal * (1 + tax)` → subtotal 6000、total 6600。
- `x = 10`, `y = x * 2`, `x = 20` → y は20のまま。後続のxだけ20。
- `x = x + 1` は既定義なら再代入、未定義ならエラー。
- 失敗した代入は更新しない。`x=10`, `x=1/0`, `x` →10、エラー、10。未定義名は追加しない。後続の独立式は継続する。
- 編集・移動・削除・追加・保存時にノート全体を再評価する。定義行を削除すれば後続参照は未定義になる。

## 構文と制限

名前は大文字小文字を区別する `[A-Za-z][A-Za-z0-9_]*`。pi/e/sqrt/abs および constructor/prototype/toString/valueOf/hasOwnProperty/__proto__ は予約。1ブロック1式または単純な `名前 = 式`。代入はASTに渡さずブロック境界で検証し、数値計算成功後のみMapへ反映する。

十進数、四則、単項±、括弧、右結合累乗、sqrt、abs、pi、eを許可する。変数モードの掛け算は明示的な `*` または `×`。x/Xは変数名。空白はtoken境界を保つため削除しない。関数定義、連鎖代入、配列、オブジェクト、属性アクセス、任意関数、科学記数法、非十進数は許可しない。

既存の入力長2000（代入名を含む）、深度32、ASTノード256、指数絶対値10000、中間の有限実数、最終絶対値MAX_SAFE_INTEGER制限を維持。%は数値の従来式のみ。変数・関数・定数・累乗との%混在は未対応。Issue #19は独立した既知の問題として継続する。

## 表示と内部精度

既存number計算の `6000*(1+0.1)` の内部値は6600.000000000001。新変数モードだけ、最寄りの非ゼロ整数との差が `2 * Number.EPSILON * abs(value)` 以下なら表示に限りその整数へ整える。例のtotalは「6,600」表示、保存するresultと後続参照は元の内部値を維持する。0付近は丸めず、1/3・sqrt(2)・巨大整数は既存formatterを維持する。通常電卓・旧ブロックの表示は変更しない。広い12有効桁への丸めは大整数まで変えるため不採用。

## 保存互換性の判断

第一希望は既存式の意味を変えず変数を追加すること。x/X一括置換を止めるだけでは旧 `2x3`、`ex2`（e×2）の意味を壊す。成功した旧式優先という推測も合法変数名ex2と衝突するため採用しない。

小さい加算変更として計算ブロックにoptionalモードを採用した。保存version1、式・結果の既存フィールドは維持し、scopeそのものは保存しない。モード欠落は従来評価固定で、開く・編集する・保存するだけでは付与しない。利用者が警告付き「変数を使う」を選ぶと変数モードへ移る。未知のモード文字列はエラーで実行しない。

旧データは新アプリで読み書きできる。一方、旧版アプリは新しいモードを理解しないため、新モードのメモを旧版で再編集・再計算することは非対応。Memo-Nexusへのコピーは表示用Markdownとして扱い、変数scopeの双方向交換は今回実装しない。

## 表示と次工程

変数は淡青、計算式は淡黄、結果は淡緑。文字ラベルも併用し、色だけに依存しない。ライト/ダークの両方を用意。表示用解析 `describeCalculationBlock` と評価処理を分離した。今後の表示設定はこの境界で切替可能。今回設定画面、共有変数、数式ライブラリ、依存グラフは追加しない。

検証結果はLOGとPRのCI・証跡リンクを参照する。Playwright WebKitはLinuxの自動検証であり、iPhone Safari実機検証とは異なる。
