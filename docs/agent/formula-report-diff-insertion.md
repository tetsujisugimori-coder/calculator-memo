# 固定引用との比較差分を本文へ挿入

## 第一希望・採用案

PR #77の比較画面から、利用者が選択した保存記録と引用時snapshotの比較を通常Markdownへ変換する。第一希望どおり既存 `compareQuoteToRecord` / `compareEvidenceRecords` を使い、別の差分エンジンや保存形式を追加しない。引用時snapshotは不変であり、差分説明は新たな本文編集である。現在取得した元記録が変更・欠落しても、検証可能な引用時snapshotを比較元として保持する。同じ登録式の保存済みリンク、同じメモID、別の記録ID、同じブロックIDによる対応付けを維持する。

生成文は登録式/メモ/引用/ブロック/前後記録の識別子、保存された日時、比較範囲、変更概要、変更行の前後の式・モード・実使用参照元/旧変数・内部使用値・表示/内部結果・順序を含む。内部数値の保存文字列と表示値を区別し、負のゼロを丸めない。同一行は概要だけ、追加・削除は片側なしと表示する。差分は観測事実であり、変更原因、編集意図、数学的正しさ、説明・証明の妥当性を自動判定しない。現在のメモ、未保存試算、再計算は混入しない。

現行v1の確定計算記録は日時と成功結果が必須である。日時欠落・エラー・結果なし等の不正記録を新たに受理せず、比較不能として止める。現在時刻や推定値で補完しない。日時が検証できない記録の部分生成は次善策だが、既存validatorと整合せず未知形式保護を弱めるため採用しない。

## プレビューと挿入境界

編集画面でのみ「差分をレポートに挿入」を提供する。保存済み詳細の比較は引き続き読み取り専用。まず同じMarkdownContentによる全文プレビューと、折りたたみ可能な原文全文を表示する。挿入先レポートID・タイトル、位置、前後記録、選択文章の保持、既存引用を更新しないこと、保存/確認が別操作であることを明示する。値は既存の動的な差分値専用コードフェンスで文字として保持し、HTMLやフェンス文字を命令として実行しない。既存rendererはインラインのMarkdownバックスラッシュを復元しないため、識別子・日時も差分値専用コードとして正確に表示する。

比較を開く時点のtextareaカーソル位置を保持し、範囲選択時は先頭へ追加して選択文章を消さない。編集欄がないプレビュー表示中は本文末尾を使い、挿入位置を確認画面で示す。コード/数式フェンスの内部・未閉鎖末尾、固定引用の可視本文と追跡フェンスの間・内部は拒否する。元本文のCRLFを含む文字列を正規化して書き換えない。新しい節として空行を挟むが、任意の外部Markdown方言の構造まで保証しない。差分データのフェンス言語は `calculation-difference-value` とし、保存文字列が固定引用のラベルを含んでも引用追跡情報と誤認しない。

プレビューは比較選択、引用、本文、保存原本、取得世代、レポート識別、タイトル、リンク編集、保存中/保護状態に結び付ける。変更時は失効し、選択・生成し直す。明示挿入直前に既存loadDataで保存原本を再取得し、準備時のrawとの完全一致を確認する。変更/取得失敗時は本文を保持し再取得を求める。元記録の現在値でsnapshotを書き換えない。保存前の原子的排他は既存保存writerの責務であり、任意の外部writerを相手にプレビューから将来の保存まで原本が固定されるとは保証しない。

## 取消・保存・互換性

「直前の差分挿入を取り消す」は直後の本文完全一致だけ許可する。本文編集、新しいテンプレート/引用/差分挿入、保存成功、レポート切替で古い取消を失効させ、他の専用取消とは同時保持しない。ブラウザ標準Undoの完全互換は保証しない。保存失敗は本文を保持し、成功表示を出さない。

生成、プレビュー、取消、比較選択、本文挿入は保存・確認履歴追加・計算を行わない。既存の明示保存/確認、競合検知、読戻し、未知形式保護、原本JSON退避を維持する。通常保存後の再確認状態も既存判定のまま。

本文100,000文字と全関連レポート1,000,000バイト、リンク/確認履歴件数を変更しない。挿入準備と直前に全レポートを既存readFormulaReportsで検査し、保存済み未知フィールド・履歴と編集中タイトル/リンクも含めて見積もる。最終保存・確認時の増分は既存厳密検査が責任を持つ。超過時は全文拒否し、自動切詰めや履歴削除をしない。

schema/version変更・移行はない。コピー/Markdown出力は新節を含む本文を保持する。次善策の別メタデータ保存や引用の自動追従は不採用。ロールバックはこの機能のコード/試験/文書をrevertし、追加した通常Markdown本文はユーザーの文章として保持できる。既存引用や原本の書換え・削除は不要。

## UIと検証

既存Modalと縦配置/折返しを再利用し、識別子や全文を横スクロール前提にしない。ネストしたプレビューはEscape/閉じるで比較操作へ戻り、挿入後は編集欄へ戻る。状態は文章で示す。

単体・UI回帰は固定snapshot、実使用値、内部/表示、負のゼロ、不正/未知/欠落、本文/引用全体保全、容量、プレビュー失効、取消、保存原本不変を対象とする。GUIは既存Chromium/WebKitの6条件、両テーマ200%、375/390px、既存30分・114PNG・成功trace非保存の契約内で追加する。実行結果と実CIはLOG/PR Checksに記録する。実機iPhone Safari、VoiceOver、OSソフトキーボードは自動ブラウザ試験とは別で未検証。
