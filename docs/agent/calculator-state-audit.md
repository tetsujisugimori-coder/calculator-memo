# 計算状態の調査（2026-10-18 JST）

基点は PR #17 マージ後 main `f6ae38a972575858db7236ad1a9846a61ec16e88`。
[Issue #18](https://github.com/tetsujisugimori-coder/calculator-memo/issues/18) の調査記録。
PR #13 の既存仕様と共通入力関数を維持し、全面状態機械への変更は行わない。

## 状態と遷移

| 操作 | 編集中・復元直後 | 確定直後 | エラー後 |
| --- | --- | --- | --- |
| 数字・小数点・左括弧 | 現在式へ追加 | 新規式 | 新規式 |
| 四則演算子 | 末尾の入力規則で追加・置換 | 数値結果から継続 | 失敗式を訂正 |
| BS | 元式の末尾1文字削除 | 元式を再編集 | 失敗式を再編集 |
| CE | 末尾数値を消去 | 元式の末尾数値を消去 | 失敗式の末尾数値を消去 |
| ± | 末尾数値の符号を反転 | 元式の末尾数値を反転 | 失敗式の末尾数値を反転 |
| C / Escape / Delete | 空の編集状態 | 空の編集状態 | 空の編集状態 |
| 右括弧・% | 元式に追加 | 元式を再編集 | 失敗式を訂正 |
| = | 評価成功なら確定、失敗ならエラー | 同じ式を再評価 | 失敗式を再評価 |

すべての入力・編集操作は確定結果を無効化し、エラーを解除して編集中へ移る。入力ヘルパーが変更を拒否した場合やCE対象がない場合も同じ保守的挙動を維持する。成功した再計算までは単独計算メモの両入口が無効。編集だけでは履歴・既存メモを変更しない。正常計算だけ履歴に保存し、短時間の同式重複抑制を維持する。

履歴と単独メモからの復元・URL入力は編集中で、自動計算・自動履歴保存はしない。復元直後の下段は末尾数値。繰返し＝による前の演算の反復機能はない。

## 確認した不具合と修正範囲

1. 小さい結果 `1/10000000=1e-7` のあと `*2=` は `String(resultValue)` が指数表記を作るため許可文字エラーになった。継続演算子をBSで除いたあと±/CEも指数部を誤って編集した。継続時に限り数値の最短文字列表現を同値の通常十進表記へ展開する。表示の丸めや桁区切りを流用しない。
2. URLの `12 * - 34 ` は正常評価できるが、末尾空白により下段0・CE無変更・±が未閉じ括弧を追加した。`12 × − 34 ` のUnicode符号も評価時と編集時で意味が異なった。末尾空白を除き%直前の空白も許容して数値位置を検出し、単項符号判定と数値テキストに既存の正規化を適用する。元式の演算子と位置は保持する。

数値の範囲は既存の有限値かつ `abs(value) <= Number.MAX_SAFE_INTEGER` のまま。最小subnormalも十進文字列へ戻せる（最大約327文字の符号付き小数）；任意精度を追加するものではない。浮動小数の誤差は保持する。外部からの指数構文は引き続き拒否する。正の指数は通常の確定結果範囲では発生しないが変換単体の境界として確認し、範囲外評価は拒否される。非有限状態も評価で拒否され、Appの正常確定からは生成できない。

PR13の `12+3=15 → BS/CE →4 =16`、`±→=9`、未編集の`+2=17`を変えない。

## 別件と判断保留

- ネスト括弧への%は評価器の既存不具合。[Issue #19](https://github.com/tetsujisugimori-coder/calculator-memo/issues/19)へ再現・期待値・影響経路を記録。括弧の対応を含む後置演算の変換規則が必要で、計算ブロック/メモ保存時にも影響するため状態遷移修正と分ける。未解決である。
- `±`の対象数値がない場合は既存の`(-`等を挿入し、閉じ括弧は手入力が必要。閉じ括弧末尾のCEは無変更。演算子連続入力の一般仕様もここでは再定義しない。式全体・括弧結果の符号反転という新機能には変更しない。
- レイアウト、保存形式、依存、workflow、公開サイトは変更しない。

## 検証と限界

追加した単体は小さい正負数、4演算、MIN_VALUE、−0、最大安全値、精度保持、範囲外/非有限、訂正、空白/Unicode符号、括弧エラー復帰を含む。修正前の指数回帰は10件失敗し、修正後に成功した。独立の数値探索10,021有限値は変換後のNumber同値、うち評価範囲内5,454件はmathjsでも同値だった。

GUIは既存のChromium/WebKit 6条件を保持し、小数結果継続、確定後の符号/CE、URL訂正、括弧エラー復帰、単純括弧%、メモ/履歴のpayloadと再読込を追加。実行結果と最終SHAはLOGとPR Checksへ記録する。実機iPhone Safari・OSキーボード・native文字拡大・長期保存は未検証。
