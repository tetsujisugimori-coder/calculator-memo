## 同一性・比較の意味
同じ登録式/レポートの異なる固定記録を明示選択する。根拠は種別＋安定quoteId/differenceId、各側とメモID、計算ブロックはblockIdで対応する。配列位置や本文順で同一性を推定しない。重複/欠落は対応不能とし、追加削除や一致へ強引に分類しない。引用時snapshot同士と取得時snapshot同士は別に比較し、不足した取得原本を引用時記録で代用しない。

式・実入力/参照元・内部結果・表示結果は既存差分エンジンで分離。参照先ID等の記録構造差と点検状態差も別に扱う。同じ計算記録IDの2観測にも比較を許す限定オプションを追加するが、既存比較UIの異なる記録ID必須契約は既定値で保持する。丸め差から内部値変化を推定しない。理由は記録されていないため理由不明とする。項目別状態と総合状態は併存可能。数学的正しさ・真正性・変更意図・外部原本との原子的整合は証明しない。

## 失効・保存保護
比較は読み取り専用・同期処理。初期表示時は実行せず、A/B選択/入替後に明示比較。本文/レポート/登録式/再取得/取得失敗/保存通知で結果を破棄する。親が旧dataを保持するstorage競合でも通知世代を伝播し、保存本文との一致未確認は出典照合の成功で解除しない。通知だけで対象の変更/削除と断定しない。再比較しても過去2記録間の比較に限定する。

過去領域/snapshot/保存原本/確認履歴を書換えず、自動保存/再計算/確認/本文挿入はない。未知/不正境界を推測回復せず、移動は現在の有効な領域位置のみ。旧記録は日時が取れなければ不明、本文順を日時順と呼ばない。
