# 保存済み計算メモのMarkdownレポート

## 対象と読み取り境界

Issue #47。PR #46マージ後 main `08d92a2`を基点とする。保存済みブロック型「計算メモ」の詳細に「レポート出力」を追加する。単独計算メモ・登録式・履歴の直接出力、PDF/印刷、AI証明生成、自動送信/双方向同期は対象外。

明示的に開いた時だけ`MarkdownReportModal`が既存`loadData()`からブラウザ保存原本を読み直し、IDとtypeを確認する。メモリ中の画面データや編集draftへフォールバックしない。保存エラー、対象消失、未知/壊れた構造は出力を拒否し、原本JSONの既存保護を維持する。開いた時点のsnapshotをコピー/ダウンロードで共用するため、別タブ更新を反映するには閉じて開き直す。

`buildMarkdownReport`は保存noteを読み取る純粋関数。`resolveMemoBlocks`の状態補正は使わず、原本blocks、または旧contentのみメモの文章を読む。計算、試算、反映、rollback、保存、履歴、登録式、localStorageへの書込みは呼ばない。schema/versionも変えない。

## 構成と数値

タイトル/基本情報、原本順の本文・数式・計算、依存図、状態と注意事項、未記入の解説・根拠追記欄を出す。文章と計算を別章に並べ替えない。計算式は元の入力をtextフェンスで保持し、勝手にLaTeXへ変換しない。保存表示値と保存内部数値を別々に載せ、内部値に丸めや再計算を加えない（負のゼロも区別）。

- 保存errorがあれば保存された計算エラー。現在の式を再評価した意味ではない。
- resultがnullなら未計算/結果なし。
- `staleBlockIds`の既存署名照合と依存伝播、静的診断により古い可能性を表示。
- current＋署名一致、依存状態も問題なしの場合のみ「確定済みの結果（保存署名と依存状態を照合。再計算は未実行）」。署名は改ざん検証ではない。
- 署名のない旧方式等は状態不明。数値の存在だけで確定しない。
- attemptErrorを含む矛盾した輸入snapshotも、一括確定失敗として全計算の確定表示を抑える。評価器の規則は変更しない。

未保存draft、試算の観測値/差分、比較基点は受け取らない。計算可能性は証明成立と異なる。解説・証明・導出・由緒・条件・参考資料は一つの未記入欄とし、存在しない史実や出典を作らない。

## 依存関係

既存`analyzeMemoDependencies`と`toMermaid`を利用。安定ID、ID確定依存/旧変数不確定候補、解析診断、循環/参照切れを保持する。図のノード状態もレポートと同じ判定を渡す。128計算ブロック等の既存解析上限や例外では、完全図と称さず理由を出し、文章・保存式・値・参照一覧の出力は残す。新しい描画器やHTML/SVG出力はない。

## Markdown安全性・限界

生成するタイトル/メタ情報/診断はMarkdown記号とHTMLを文字として保護し、改行を一行へ整える。入力式/値/エラーのコードフェンス長は内容中の最大連続バッククォートより長くする。本文はMarkdownを維持し、未閉鎖コード/表示数式を出力内だけで閉じる。コードと数学の字句状態を分離する。通常LaTeXの`&`などは保持し、HTML記号/コードフェンスを含む数式や区切り入りの表示数式は元のコード表示へ退避し注意事項へ記録する。

本文のHTMLはエスケープし、独自の行頭`:::`ディレクティブは文字として表示する。これは一般Markdownを特定製品の実行ブロックへ変換しないためで、文章を削除しない。第三者Markdownエンジンの完全サニタイザーではない。受け取り先でも安全設定を維持し、リンク/画像/プラグイン等の実行・ネットワーク動作はその環境に依存する。原本JSONの完全バックアップではなく、未知の付随フィールドは変更せず解釈/掲載しない旨を明記する。

入力JSON100万文字を超えた場合は、黙って切り詰めず出力拒否。ファイル名は不正パス文字/制御文字/予約名/空名を処理し、80Unicode文字・拡張子込み200UTF-8 bytes以下にする。UTF-8化で欠落する孤立サロゲートはファイル出力拒否。readonly textareaは生ソース確認であり、完全なMarkdown描画プレビューと称さない。コピーはpromise成功後に表示、ダウンロードはブラウザへの要求でありOS保存完了を保証しない。
