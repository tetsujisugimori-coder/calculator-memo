# 根拠点検と本文の往復ナビゲーション（Issue #98）

設計記録：2026-10-27 22:53 JST。基点 main `035436c3c0dc3a971d1a3c4bb77fb8d1c3a11066`（PR #97 merge実確認）。

## 方針とデータフロー
- 第一希望は既存 scanner・本文移動・点検画面の再利用。独立したMarkdown解析器、新永続形式、多重モーダルは追加しない。
- 点検セッション内の戻り先は現在のレポート識別、対象種類、出現range、stable ID、対象の完全bytes、取得世代、絞り込み、選択、一覧scroll、focusに限る。一時React状態で保持し保存しない。
- 通常往復では点検モーダルを一時休止し、既存の一覧・比較結果・詳細選択を保持する。休止中はmodal stack/focus trapから外し、本文編集を妨げない。再開で保存原本を再取得・再比較しない。
- 対象変更時は旧詳細／取得結果を無条件復元しない。本文変更では既存scannerで再列挙し、同じstable IDと完全bytesを持つ正規出現が一意のときのみ位置を再解決する。元位置・近似文章・後方終端から推測しない。
- 同一ID重複を認めない既存保護は維持。同じ表示文／出典を持つ異なる正規IDの出現は別対象。資料内の文字列を独立候補へ格上げしない。

## 強調と操作
- 既存本文移動の選択範囲・スクロールを維持し、独立した一時移動先ラベルと完全対象抜粋を併用する。色だけで伝えない。本文へのマーカー挿入や保存、textarea内容変更はしない。
- 『点検へ戻る』『本文の対象へもう一度移動』『往復ナビゲーションを終了』を明示。戻らず本文を編集することもできる。
- 編集中は古い強調範囲を表示せず失効を明示。遅延RAFは本文編集世代・実選択・レポート・保存通知・要求世代を直前照合。close/unmount/新操作で旧処理を取消す。

## 保存保護・保証しないもの
navigationは原本取得、保存、自動保存、再計算、明示確認、履歴追加、比較再実行を行わない。snapshot、schema、容量、engine、Markdown生成、挿入／専用取消は変更対象外。保存通知は保持本文との一致未確認を維持。位置特定は保存原本との一致／真正性／数学的有効性の証明ではない。

## 受入条件
通常／連続往復、filter・選択・scroll・focus、独立出現、前後加筆、削除・改変・重複・不完全・未知、storage更新削除、ABA／遅延、report/session閉鎖、keyboard/touch、小画面両theme200%、本文／保存／snapshot／履歴の不変性を検証する。既存単体・契約・lint・型・両build、正式6 GUI条件を維持し追加。実機Safari／VoiceOver／OS文字拡大は別の未検証。実装・検証未完了時点ではPASSを記録しない。
