# JSONバックアップの選択復元プレビュー（第1段階）

## 目的・受入境界（実装前に固定）

Issue #112。main `2549c8c15d9a5e4cea052eabc0020ad03104b49a` と PR #107/#109/#111 の統合を確認して開始。
今回は **閲覧・比較・候補選択だけ**。復元は実行できない。通常保存原文、バックアップ原文、復旧コピーを変更せず、選択は画面内メモリだけに置く。部分復元・ID変更・参照修正・snapshot再生成・自動移行・クラウド同期は行わない。選択できても将来の安全な復元を保証しない。

## 設計

- 入力は既存 `calculator-memo-backup` version 1。外側と内部の未知version、不正JSON、重複キー、容量超過は拒否。既存厳格JSON検査と全体復元検証を再利用し、既存ローダーによる補正後の値を原文へ書き戻さない。
- ファイルは読み込む前にサイズを確認する。16 MiBのファイル上限、2,097,152 UTF-16コード単位の内部原文、深さ128を超える解析は行わない。全体100,000要素・一覧5,000項目を上限とし、超過は切捨てず停止する。一覧20件・詳細4,000文字・参照20件でページ分割し、候補選択は最大200件。全項目を同時描画しない。環境のメモリ成功を保証しない。
- 主要分類は履歴・メモ・登録式・実行入力・関連レポート・根拠記録・確認履歴・その他。現物の保存構造に基づく。未知・未対応・不正な要素はUNKNOWNとして明示し、正常0件へ変換しない。
- 項目の詳細はエスケープされた読み取り専用値。式評価、Markdownの生HTML実行、確認履歴作成はしない。原文文字列と解析済み表示は区別する。
- 比較は種別と一意なID（実行入力は保存構造のformulaId、入れ子記録は親IDスコープ）による対応と、構造的内容比較を分離する。ID不在・重複・対応曖昧はUNKNOWN。同一内容は原文の空白・数値字句の一致ではない。
- 現在保存原文は明示操作で取得。未取得・読取失敗・検証不能・失効を区別し、古い成功を残さない。storage通知、同一タブの世代/状態変化で比較を失効する。再取得は明示操作のみ。取得時刻を表示する。
- 参照はバックアップと現在の名前空間を分け、確認できた一意な参照先・欠落・曖昧・未対応・解析不能を表示。固定snapshotを再生成しない。参照が見つかっても復元後の整合性保証ではない。
- ファイル変更で古い選択・比較・詳細を失効。選択の集計は種別、変更/衝突/参照不足/不明を表示。復元実行ボタンは設けない。
- 親画面の保存処理とキーボード副作用を防護する。localStorageのCASや完全なtransaction、旧クライアント・通知前ABAの完全検知は主張しない。

## 比較の厳密な意味と数値

1. **原文保持**: `raw` は取得したUTF-16文字列そのものを保持し、解析結果から再生成しない。この保持性と項目の意味的比較は別。
2. **構造比較**: 同じ種別・親スコープ・一意IDの全フィールドを比較する。オブジェクトのキー順・JSON空白は無視し、配列順は維持する。`Object.is` により `-0` と `0` を区別する。`1e2` と `100`、`1.0` と `1` は十進数として同じ内容と扱うが原文字列一致とは呼ばない。
3. **UNKNOWN**: JavaScript安全整数範囲を超える整数、非有限数、数値字句をNumberへ変換して戻した時に十進値が変わる小数/underflowは一致と認定しない。例 `1.00000000000000001` と `1` は解析値が同じでもUNKNOWN。巨大な指数は巨大整数や累乗を確保せず桁列と指数を正規化して検査する。不明を勝手に丸めて正常化しない。
4. **不完全な文書**: 未知collectionや重複ID等を含む原文は保守的にUNKNOWNとして比較する。未対応分類の件数は0でなくUNKNOWN。既知の一部項目も文書全体の検証不能により比較不能となる場合がある。

実行入力には独立idがなく `formulaId` を自然キーとして用いる。根拠記録はメモID、確認履歴はレポートIDを親スコープとする。設定は保存構造の固定キーであって利用者データの実IDではない。固定引用と差分の構造化参照は既存parserを読取専用で利用し、点検記録/比較記録の過去snapshotの全参照解析や変数名依存は未対応と明記する。

同一タブの非協調書込は取得原文の500ms検証・操作前照合・focus/visibility確認で検出する。これは自動再取得ではない。500ms未満の変更・通知前・ABAまで完全検知する保証はない。比較失効後、元の結果へ自動復帰しない。
