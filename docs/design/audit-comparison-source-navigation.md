# 固定A/B比較資料の出典追跡・本文ナビゲーション

## 読み取り専用データフロー
表示中本文 → 既存Markdown block parser → 既存固定比較資料・固定点検記録scanner → 一覧／詳細／出典解決 → 世代を再検証した本文選択。保存原本を取得せず、比較・計算・保存・履歴追加は行わない。

既存scannerの領域とcomplete判定のみを移動の根拠とする。診断用のclaimedIdはJSONに書かれた文字列という観測値であり、検証済metadataとは分離する。診断は既存parserのcode blockとscanner内の厳密なmetadata検査を再利用し、別の境界解析器を設けない。入れ子の比較資料は外側の固定点検記録に含まれる資料として独立一覧から除外する。交差・未知・壊れた範囲があれば一覧／出典検索の完全性を主張しない。

## 識別と表示
比較資料のmaterialId、formulaId、reportId、beforeRecordId、afterRecordId、preparedAtのみが構造化保存されている。preparedAtは挿入プレビュー準備日時で、保存日時ではない。比較状態・比較不能理由は構造化保存されていないため固定本文をそのまま示し、文章から抽出・再判定しない。

出典移動は同じformulaId/reportIdの、completeかつclosedな一意の固定点検記録のみ。比較snapshotを持たないv1も出典としては扱えるが再比較可能とは表示しない。未知・破損・重複の診断IDは移動に使用しない。未識別の不正領域が残るときは、該当IDが見つからなくても「不存在」と断定しない。固定比較資料内部の点検記録は候補にしない。

## 位置・失効
parserの位置は元本文のUTF-16、end exclusive。整数・範囲・順序・サロゲート境界・CRLF途中を検査し、textareaではCRLF/CRを一度だけLF換算する。選択時と移動時に本文・対象・storage通知世代を照合し、古い非同期移動を拒否する。新しい移動要求は前の遅延要求を失効させる。storage通知後も保持本文と保存原本は別物で、一致保証は行わない。

## 変更禁止・対象外
scannerの保護範囲、固定資料生成bytes、保存schema、snapshot、計算エンジン、確認履歴、PR95の挿入・取消を変更しない。出典追跡は真正性・現在原本との一致・数学的証明を保証しない。実機Safari、VoiceOver、OS文字拡大、既存WebKit時間変動・100ms fixture環境差・過去選択位置ずれ原因の解消は別途証拠が必要。

## 交差診断の限定用途
比較資料が旧点検記録の開始だけを内部に隠し、終端が外に残る場合、通常scannerは内側開始を除外する。比較marker blockだけを除いた既存点検record scannerの補助走査でclosedな交差範囲を検出し、移動拒否のみに使用する。補助走査のmetadataは出典候補に使わない。資料内部だけに収まる点検記録、未閉鎖のrecord風文字列は新しい出典へ昇格させない。invalid領域内へ飲み込まれた同一IDのstart観測も診断の重複拒否に用いるが、その位置へ移動はしない。

## 採用理由・失効の補強
第一希望は既存scannerと本文範囲の再利用。独立parserや新形式は互換性・自己参照防止・保守性の負担が増すため採用しない。既存の比較結果builder・保存形式は不変で、資料全文は元本文のsliceそのものを使用する。

本文が編集後に同じbytesへ戻った場合も、本文編集世代を比較して旧移動を拒否する。native select通知前の選択変更は、要求時に捕捉した実selectionStart/Endを実行直前に照合する。render用通知世代はReact state、同turnの旧イベント拒否は同期refに分離する。新移動要求・対象変更・unmount・storage通知も旧RAFを失効させる。これらは本文変更・保存ではなく、遅延した誤移動の拒否である。
