# JSONバックアップの設計

## 対象と形式

製品コードの `localStorage` 読書きは `lib/storage.ts` に集約され、所有キーは `calculation-memo:data` のみ。保存形式 version 1 の単一原文に `history`、`notes`、`settings` と、optional の `formulaLibrary`、`formulaExecutions`、`formulaReports` がある。単独・ブロック・変数メモおよび計算根拠は `notes`、snapshot・確認履歴等はレポートやメモの内部にあり、固定引用・比較・点検の記録はレポート本文内に含まれる。未知フィールドも原文の一部として保持する。セッション上の編集、他アプリのキー、認証情報は探索しない。

形式名 `calculator-memo-backup`、形式version 1。`acquiredAt` は取得時、`createdAt` はJSON生成時のUTC日時。`appStorageVersion` は安全な整数として読める値、判定不能はnull。`acquisition` は captured、`entries` はキー、原文 `raw`、UTF-16コード単位の長さ、現行ローダーの `validation`、読み取れる場合の主要配列の `counts` を含む。原文は文字列として JSON に格納し、解析結果から再構築しない。JSONのエスケープを再解析した文字列は改行・Unicode・未対サロゲート・未知フィールド・巨大な数値表記を含めて元のUTF-16文字列と一致する。

`validation: ok` は現行ローダーが受け入れたことに限る。ローダーは履歴の一部を除外し設定を補正するため、全項目の完全性の証明ではない。これらの正規化結果はバックアップ原文に使わない。件数は元JSONの主要配列を数え、読み取り不能や未知形式ではnull。存在しないキー、保存領域の取得失敗、サイズ超過は出力しない。空の正常データは0件、空文字は不正JSONとして原文を保持する。破損・未知versionの原文は状態を付けて出力可能で、保護解除・修復・移行をしない。

## 操作・競合・限界

取得中に同一キーを二度読み、書き出しの直前と生成後にも原文を再比較する。別タブのstorage通知を受けたら同値通知も同期的に失効させ、再取得まで出力しない。再取得前の画面状態からの同一ターン操作も拒否する。比較間のABA変更、通知前の競合、別端末や古いクライアントのすべての変更は検知できず、ブラウザ全体の原子的スナップショットやディスクへの永続化は保証しない。

取得できる原文は2,097,152 UTF-16コード単位まで。JSONの構築・Blob等は追加メモリを使い、環境によってはこの範囲でも失敗する。失敗は元データを変更しない。容量表示のバイト相当はUTF-16コード単位×2であり、ブラウザの実際の保存割当やJSONファイルのUTF-8サイズではない。ブラウザへの要求後もOSへの保存完了は確認不能。Blob URLとdownload属性を明示操作で使い、WebKitが取得する前に解放しない。実機iPhone Safari、OS文字拡大、プライベートブラウズ、長期保存は未検証。

バックアップは読取専用で、計算、確定、履歴追加、確認、snapshot更新、本文変更、未保存編集の保存を行わない。復元・同期・クラウド保存は実装しない。復元を別途設計する際は、プレビュー・差分・明示承認と失敗保護を検討する。
