The loopback harness (`node e2e/physical/server.mjs`) is not reachable from an iPhone; do not bypass that boundary. A separate approval must identify an access-controlled HTTPS test origin and its access scope before deployment. Before a future authorized trial: record immutable build HEAD/tree and source hashes, date/time/timezone, device model, OS and exact Safari version, normal/private/standalone mode, trial UUID and expected case. Use only the page's generated synthetic DB. Export before any navigation and after diagnosis. Missing export, process interruption or lost events is INCOMPLETE/UNKNOWN, not successful completion. JSON exported by this page is manual-unverified; independently audit it before accepting any observational claim. There is no physical-PASS button.

Future cases, each separate UUID: normal write/read; reload readback; close/reopen using the exported UUID namespace and Attach read-only button; background/resume; two tabs; private session; standalone app comparison. Record saving request, request success, native same-transaction complete/abort, receipt/current/generation/operation, later independent readback, and elapsed time separately.
